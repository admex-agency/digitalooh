# admeX x Admicro Ratecard Website

Website HTML/CSS/JS thuần, có thể upload trực tiếp lên GitHub Pages.

## Deploy nhanh
1. Giải nén file ZIP.
2. Tạo GitHub repository mới.
3. Upload `index.html`, `README.md`, và thư mục `assets`.
4. Vào Settings → Pages.
5. Source: Deploy from a branch. Branch: `main`. Folder: `/root`.
6. Save và chờ GitHub Pages tạo link.

## Tính năng
- Tra cứu ratecard theo sheet/đối tác.
- Search/filter offline.
- Ask admeX: trợ lý tra cứu nhanh bằng prompt gợi ý, không cần API key.
- Có thể tải CSV theo sheet.
